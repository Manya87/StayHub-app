# StayHub Frontend (`frontend-owner`)

React + Vite frontend for the StayHub application.

## Prerequisites

- Node.js 18+
- npm

## Setup

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Scripts

- `npm run dev` - start development server
- `npm run build` - create production build
- `npm run preview` - preview production build
- `npm run lint` - run ESLint
